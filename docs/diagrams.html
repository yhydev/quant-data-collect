6. API 接口

POST /api/open-position

开仓接口

Body: {
    "contract": "BTCUSDT",
    "batch_num": 1,
    "batch_position_value": 1000,
    "order_plugin": "futures_first"
}
Response: { "status": "success", "message": "..." }
POST /api/close-position

平仓接口

Body: { "position_id": 1 }
Response: { "status": "success", "message": "..." }
GET /api/funding-rates

资金费率查询

Response: [{ "symbol": "BTCUSDT", "rate": 0.0001, ... }]
GET /api/positions

持仓列表

GET /api/health

健康检查

Response: { "status": "ok", "database": "healthy" }
